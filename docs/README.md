## Что это за проект

LeadFlow — full-stack CRM/ERP для розничной и оптовой торговли (целевой рынок — Центральная Азия). Backend: FastAPI + async SQLAlchemy 2.0 + PostgreSQL. Frontend: React 19 + Redux Toolkit (RTK Query) + Tailwind CSS. Система покрывает цикл: клиенты → каталог → заказы → склад → поставки → финансы → зарплата с KPI.

## Методология

Всё, что написано ниже, проверено непосредственно по коду (грепы по роутерам/моделям/зависимостям, чтение репозиториев, реальные запросы к работающему backend на `localhost:8000`, `npm audit` / `pip-audit`). **Целевой хостинг подтверждён командой (не выводится из кода однозначно): Render.com.** ✅ Мёртвые/устаревшие следы Fly.io (`Dockerfile-backend`/`Dockerfile-frontend`, битый `nginx/default.conf`) удалены/исправлены 2026-08-29 — подробности в [CHANGELOG.md](../CHANGELOG.md) и [setup.md](./setup.md#деплой).

## Итоговая оценка (коротко)

Система функционально насыщена и не является прототипом: 30+ доменных сущностей, ~155 API-эндпоинтов, 27 RTK Query слайсов на фронте, реальная бизнес-логика (списание/возврат склада при заказах, аудит истории заказов, генерация зарплаты по KPI, ABC/XYZ-анализ, P&L-отчёт, импорт/экспорт каталога, сканер штрихкодов). Для внутреннего использования командой из нескольких десятков сотрудников — функционала достаточно уже сейчас.

**Обновление 2026-08-29**: критичные находки первого прохода аудита (каскадное удаление данных при удалении клиента/филиала, отсутствие проверки владения заказом, сломанный деплой на Render, отсутствие тестов на заказы/зарплату) — устранены, см. [CHANGELOG.md](../CHANGELOG.md). Для передачи внешним клиентам или роста до сотен пользователей остаются пробелы: RBAC доведён до записи для 5 из ~9 доменов (остальное — грубая проверка «админ/не админ»), автотестами всё ещё не покрыты поставки/финансовая аналитика/переводы остатков, во фронтенд-зависимостях подтверждено `npm audit` 3 high-severity уязвимости, в бэкенд-зависимостях `pip-audit` нашёл 84 известных advisory в 20 пакетах (в основном транзитивные/dev, но есть и в `cryptography`/`starlette`/`python-multipart`, задействованных в каждом запросе) — версии не обновлялись.

Подробности и приоритизация — в [gaps-and-roadmap.md](./gaps-and-roadmap.md), [known-issues.md](./known-issues.md) и [CHANGELOG.md](../CHANGELOG.md).
