# Архив документации

Здесь лежат документы от 13–24 июня 2026 года, которые до консолидации
находились в корне репозитория. Как источник текущего состояния им доверять
нельзя: они отстают более чем на 40 коммитов и описывают то, чего в проекте
уже нет (например, `weasyprint`, удалённый как неиспользуемая зависимость, и
деплой на Fly.io, которого больше не существует).

Сохранены намеренно — в них есть история принятых решений по дням, которой
нет больше нигде.
